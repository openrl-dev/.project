# .project

CNCF project metadata for [OpenRL](https://github.com/openrl-dev/openrl):
`project.yaml` describes the project, `maintainers.yaml` lists maintainer
GitHub handles. CNCF automation reads both to update the Cloud Native
Landscape and provision maintainer services.

Format and validation rules: https://github.com/cncf/automation/tree/main/utilities/dot-project
